# 🚀 ENERGY+ Clean Dashboard

A modern, Tesla-inspired energy company CRM dashboard built with clean, professional design and advanced AI-powered features.

## ✨ Features

### 🎯 **Core Dashboard**
- **Tesla-inspired UI** - Clean, minimal, professional design
- **Real-time Analytics** - Live energy production and consumption data
- **Dark Mode** - Modern dark theme with neon green accents
- **Responsive Design** - Works perfectly on all devices

### 🤖 **AI Virtual Assistant**
- **Lead Finder** - AI-powered lead generation and qualification
- **AI Dialer** - Automated calling with advanced features
- **AI Chatbot** - Intelligent customer support automation

### 📊 **Marketing Tracker**
- **Campaign Analytics** - Track marketing performance in real-time
- **Social Media Metrics** - Monitor engagement across platforms
- **ROI Tracking** - Measure marketing investment returns
- **Tesla-style Graphs** - Beautiful, interactive data visualization

### 🎨 **AI Content Generation**
- **Tesla Powerwall Aesthetic** - Clean, professional interface
- **Three Content Types**:
  - **AI Copywriting** - Marketing copy, emails, social posts
  - **Image Generation** - Visual content with DALL-E 3
  - **Video Generation** - Promotional videos with Sora
- **Energy Industry Templates** - Pre-built prompts for solar/wind/efficiency
- **Real AI Providers** - OpenAI GPT-4, Claude 3.5, Google Gemini

### 📞 **Contact Management**
- **Lead Pipeline** - Track leads from acquisition to conversion
- **Client Database** - Comprehensive client management
- **Communication Tools** - Email, phone, and chat integration

### 🏠 **Installation Dashboard**
- **Interactive Map** - Real-time installation locations
- **Tesla-style Metrics** - Energy produced, CO₂ saved, cost savings
- **Installation Status** - Track project progress

## 🛠️ **Technology Stack**

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Styling**: Custom CSS with Tesla-inspired design
- **Fonts**: SF Pro Display (Apple's system font)
- **Icons**: Font Awesome 6
- **AI Integration**: OpenAI API, Claude API, Google Gemini

## 🚀 **Quick Start**

### Prerequisites
- Node.js 18+ installed
- Git installed

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/energy-plus-clean.git
   cd energy-plus-clean
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   ```
   http://localhost:3000
   ```

## 🔧 **Configuration**

### Environment Variables
Create a `.env` file in the root directory:

```env
# Server Configuration
PORT=3000
NODE_ENV=development

# AI API Keys (Optional - for real AI integration)
OPENAI_API_KEY=your_openai_api_key
CLAUDE_API_KEY=your_claude_api_key
GEMINI_API_KEY=your_gemini_api_key
```

### Customization
- **Colors**: Modify CSS variables in `styles.css`
- **Content**: Update text content in `index.html`
- **Features**: Extend functionality in `script.js`

## 🚀 **Deployment**

### **Option 1: GitHub Pages**
1. Push your code to GitHub
2. Go to repository Settings > Pages
3. Select source branch (usually `main`)
4. Your site will be available at `https://yourusername.github.io/energy-plus-clean`

### **Option 2: Vercel**
1. Install Vercel CLI: `npm i -g vercel`
2. Run: `vercel`
3. Follow the prompts

### **Option 3: Netlify**
1. Connect your GitHub repository to Netlify
2. Set build command: `npm start`
3. Deploy automatically
